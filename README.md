One X post that puts make.fun's make-your-own-bounty feature in front of more humans: describe a task, set the reward, keep a cut of every entry fee. main.ts copies POST.json to /output.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/POST.json
```
